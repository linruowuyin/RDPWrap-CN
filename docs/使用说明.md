# RDP Wrap 中文套件使用说明

> 版本：v1.0.0 | 配置：rdpwrap.ini 自动同步上游最新

## 一、这是什么

让 **Windows 家庭版 / 标准版** 等本身不支持远程桌面的系统也能：

- 开启远程桌面主机功能（被远程控制）
- 支持 **多个用户同时远程登录**（互不干扰的多会话）
- 支持同一账号同时本地 + 远程登录

## 二、适用系统

Windows 7/8/8.1/10/11（所有版本）、Windows Server 2008 R2+

## 三、安装步骤

1. **关闭杀毒软件**：Windows Defender 及其他杀软可能误报，先临时关闭
2. **右键** `install_cn.bat` → **以管理员身份运行**（自动调用安装器并写入最新配置）
3. 安装完成后会自动打开配置面板
4. **添加杀软排除项**：把 `C:\Program Files\RDP Wrapper` 加入排除列表，然后重新开启杀软

```powershell
Add-MpPreference -ExclusionPath "C:\Program Files\RDP Wrapper\"
```

## 四、中文配置面板（RDPCnC-CN.exe）

本套件提供**全中文图形配置面板**，双击即用，功能对齐官方英文面板：

| 区域 | 内容 |
|------|------|
| 诊断信息 | Wrapper 状态 · 服务状态 · 监听器状态 · termsrv 版本 · 支持级别（绿色=正常，红色=异常，每 2 秒自动刷新） |
| 常规设置 | 启用远程桌面 · RDP 端口 · 每用户单会话 · 隐藏登录用户 · 允许未注册 RemoteApps |
| 身份验证模式 | 仅图形验证 / 默认 RDP 验证 / 网络级验证 (NLA，推荐) |
| 会话影子模式 | 禁用 / 经同意控制 / 不须同意控制 / 经同意查看 / 不须同意查看 |
| 操作按钮 | 应用设置 · 更新配置(官方源/国内镜像) · 重启服务 · 系统远程设置 · 测试连接 |

> 说明：安装后中文面板会自动复制到 `C:\Program Files\RDP Wrapper\` 并默认启动。
> 英文原版面版 `RDP_CnC.exe` 保留但非必需，不需要可直接删除该文件（不影响远程桌面功能）。

## 五、更新配置（重要）

Windows 更新后如果远程桌面失效，通常只需更新 rdpwrap.ini：

- 双击 `update_cn.bat`（可选官方源 / 国内镜像）
- 或面板点「更新配置」按钮
- 安装器已创建开机自动更新任务，通常无需手动操作

## 六、常见问题

**Q1：杀软报毒？** — 行为特征（注入系统服务）导致误报，非病毒。安装前关杀软，安装后加排除。

**Q2：显示 [不支持]？** — 当前系统版本不在 ini 支持列表。更新 ini 到最新；若最新版也不支持，等待上游更新。

**Q3：远程连不上？** — 检查防火墙 3389 端口、面板三状态是否全绿、账号是否有密码、路由器端口转发。

**Q4：多用户同时登录？** — 默认支持不同账号同时登录。同账号多人需取消「每用户限制单会话」勾选。

**Q5：卸载后恢复？** — 运行 `uninstall_cn.bat`，系统恢复默认状态。
