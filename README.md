# RDPWrap-CN

让 Windows 家庭版 / 标准版支持**远程桌面被控** + **多用户同时登录**（互不干扰，像服务器一样多人共用一台机器）。

比如：你在电脑前工作，另一个人同时远程登录这台电脑用另一个账号——互不影响。

## 这是什么原理

Windows 家庭版本身不支持远程桌面被控（只能控制别人，不能被控制）。这个工具在系统服务和终端服务之间加了一层 wrapper，不改系统文件，让家庭版也能被远程控制，而且支持多个用户同时登录。系统更新后一般只需更新配置文件（rdpwrap.ini）即可恢复。

## 怎么安装（3 步）

**第 1 步：下载**

到 [Releases 页面](../../releases)，下载最新的 `RDPWrap-CN-日期.zip`，解压到任意目录。

**第 2 步：安装**

1. **关闭杀毒软件**（Windows Defender 也会拦，因为这类工具的行为特征像病毒——注入系统服务——但并不是病毒。装完加白名单就行）
2. 右键 `install_cn.bat` → **以管理员身份运行**
3. 等它跑完，会自动弹出中文配置面板

**第 3 步：加杀软白名单**

把安装目录加入杀毒软件排除列表，然后重新开启杀毒软件：

```powershell
# 管理员 PowerShell 运行
Add-MpPreference -ExclusionPath "C:\Program Files\RDP Wrapper\"
```

完成。现在别的电脑可以用"远程桌面连接"（mstsc）连过来了。

## 安装后怎么用

### 看状态

双击桌面或 `C:\Program Files\RDP Wrapper\RDPCnC-CN.exe` 打开中文配置面板：

- **Wrapper 状态** = 已安装 ✅
- **服务状态** = 运行中 ✅
- **监听器状态** = 监听中 ✅
- **支持级别** = 完全支持 ✅

四个全绿就说明正常工作。

### 改设置

面板里可以直接改：
- **RDP 端口**（默认 3389，改了记得防火墙也放行）
- **启用/关闭远程桌面**
- **每用户限制单会话**（关掉就能同一个账号多人同时登录）
- **身份验证模式**（建议选"网络级验证 NLA"，最安全）
- **会话影子模式**（控制别人能不能偷偷看你的屏幕）

改完点「应用设置」，需要重启服务的话点「重启远程桌面服务」。

### 测试连接

面板底部有 5 个按钮，点击会用 Windows 自带的 mstsc 连本机测试，不用找另一台电脑。能连上说明远程桌面功能正常。

### 远程连不上？

检查这几项：
1. 防火墙是否放行 3389 端口
2. 面板四个状态是否全绿
3. 你的账号有没有密码（空密码默认禁止远程登录）
4. 路由器/云服务器安全组是否做了端口转发
5. 面板显示"不支持"？→ 运行下面的更新步骤

## 怎么更新（系统更新后远程失效时用）

Windows 大版本更新后，远程桌面可能失效（面板显示"不支持"）。运行 `update_cn.bat` 就行：

1. 右键 `update_cn.bat` → 以管理员身份运行
2. 选 **2**（国内镜像，快）
3. 等它下载完，自动打开面板
4. 点面板上的「重启远程桌面服务」

安装时已创建开机自动更新任务，正常情况下你不用手动跑。

## 怎么卸载

右键 `uninstall_cn.bat` → 以管理员身份运行。服务卸载、文件删除、自动更新任务清除，系统恢复原状。

## 包里有什么

| 文件 | 作用 | 你需要管吗 |
|------|------|-----------|
| `install_cn.bat` | 安装脚本 | 安装时右键管理员运行 |
| `uninstall_cn.bat` | 卸载脚本 | 卸载时右键管理员运行 |
| `update_cn.bat` | 更新配置脚本 | 远程失效时右键管理员运行 |
| `RDPW_Installer.exe` | 安装器（安装脚本会调用它） | 不用直接动 |
| `RDPW_Uninstaller.exe` | 卸载器（卸载脚本会调用它） | 不用直接动 |
| `RDPCnC-CN.exe` | 中文配置面板（看状态、改设置） | 安装后双击打开 |
| `rdpwrap.ini` | 补丁配置（支持哪些系统版本） | 不用动，自动更新 |
| `docs/` | 使用说明 | 想看就看 |
| `SHA256SUMS.txt` | 文件校验 | 确认下载完整性用 |
| `VERSION` | 版本号 | 不用管 |

## 常见问题

**Q：杀毒软件报毒？**
正常。这类工具要注入系统服务，行为特征和病毒类似，但不是病毒。装前关杀软，装后加白名单。

**Q：能同时几个人远程登录？**
不同账号可以同时登录，互不干扰。同一个账号多人同时用的话，在面板里取消「每用户限制单会话」。

**Q：安装后本地还能用吗？**
能。远程用户和本地用户可以同时在线，各看各的屏幕。

**Q：和向日葵/ToDesk 有什么区别？**
向日葵/ToDesk 是"远程控制"（一个人看屏幕操作），多人不能同时用。这个是"远程桌面"（多人各自独立会话，像服务器一样），完全不同的东西。

**Q：支持哪些系统？**
Windows 7/8/8.1/10/11 所有版本（家庭版、专业版都行），Server 2008 R2+。
